
# AI Cover Letter Generator

An AI-powered cover letter generator that creates personalized and professional cover letters using the user's personal information, resume, and job , skills.

## 🚀 Tech Stack 

### Frontend

- React.js
- Tailwind CSS
- Vite

### Backend

- Node.js
- Express.js

### AI

- AI API for generating personalized cover letters

## Other Tools

- Git & GitHub
- VS Code
- PDF Parser for extracting text from resume

## ✨Features

- Enter Your Information(Name, Job Role, Target Company, Key skills)
- Upload resume in PDF format
- Extract information from uploaded resume
- Generate AI-Powered personalized cover letters
- Match resume experience with job requirements
- Display generated cover letter
- Easy to copy cover letter output
